# 🌾 Ss Seed Shop — cPanel ডাটাবেস আপডেট ও অপটিমাইজেশন গাইডলাইন

## 🛠️ ২. cPanel-এ ডাটাবেস কীভাবে আপডেট করবেন?

আপনার জন্য ডাটাবেস আপডেট করার **২টি অত্যন্ত সহজ পদ্ধতি** তৈরি করে দেওয়া হয়েছে। যেকোনো একটি পদ্ধতি অনুসরণ করলেই হবে। আপনার কোনো বর্তমান ডাটা ডিলিট হবে না।

---

### 👉 পদ্ধতি ১: ১-ক্লিকে ব্রাউজার দিয়ে অটোমেটিক আপডেট (সবচেয়ে সহজ ও রিকমেন্ডেড)

আমরা `api/cpanel_database_update.php` নামে একটি অটো-আপডেটার টুল তৈরি করেছি।

১. গিটহাবে পুশ করে আপনার লাইভ সার্ভারে কোড নামানোর পর বা cPanel ফাইল ম্যানেজারে আপলোড করার পর ব্রাউজারে এই লিংকে যান:

```
https://api.ssseedshop.com/cpanel_database_update.php
```

_(যদি লোকালহোস্টে টেস্ট করতে চান: `http://localhost:8005/cpanel_database_update.php`)_

২. পেজটি ওপেন হওয়া মাত্র স্ক্রিপ্টটি নিজে নিজেই:

- ডাটাবেস কানেকশন চেক করবে।
- সব মিসিং কলাম ও নতুন টেবিল যোগ করবে।
- দ্রুত লোডিংয়ের জন্য সব ইনডেক্স (Indexes) তৈরি করে দিবে।
- স্টক আউট ও ইন-স্টক ডাটা সিনক্রোনাইজ করে দিবে।
- কোনো প্রডাক্টের ছবি বেশি ভারী আছে কিনা তা স্ক্যান করে রিপোর্ট দেবে।
  ৩. স্ক্রিনে একটি সুন্দর গ্রিন ড্যাশবোর্ড দেখতে পাবেন যেখানে লেখা থাকবে: **"ডাটাবেস সম্পূর্ণ আপ-টু-ডেট এবং অপটিমাইজড!"**

## 🔐 ৩. cPanel-এ `.env` কনফিগারেশন যাচাই

cPanel ফাইল ম্যানেজারে গিয়ে নিশ্চিত হয়ে নিন যে `api/.env` ফাইলে ডাটাবেসের ইউজারনেম ও পাসওয়ার্ড সঠিক দেওয়া আছে:

```ini
DB_HOST="localhost"
DB_NAME="jjcceicf_ssseedshop"
DB_USER="jjcceicf_ssseedshop"
DB_PASS="8.GdFreD&XPEWzC."
```

## ⚡ ৪. প্রডাক্ট লোডিং সুপারফাস্ট রাখার জন্য অতিরিক্ত পরামর্শ

1. **ইমেজ সাইজ:** এডমিন প্যানেলে যখন নতুন প্রডাক্ট যুক্ত করবেন বা ছবি আপলোড করবেন, তখন ১০০-৩০০ KB-র মধ্যে WebP বা JPG ফরম্যাটের ছবি ব্যবহার করার চেষ্টা করবেন।
2. **সার্ভার ক্যাশ:** পরিবর্তন করার পর ব্রাউজারে `Ctrl + Shift + R` চেপে একবার হার্ড রিফ্রেশ করে দেখে নিবেন। এখন প্রডাক্ট লোড হতে গড়ে ১০০ থেকে ৩০০ মিলিসেকেন্ডের বেশি সময় লাগবে না!

## 🐘 ৫. PostgreSQL (পোস্টগ্রেস)-এ কনভার্ট করার নিয়ম

আপনি যদি ভবিষ্যতে MySQL থেকে PostgreSQL-এ মাইগ্রেশন করতে চান (যেমন: **Supabase** বা **Neon.tech** ক্লাউড ডাটাবেস ব্যবহার করে), তাহলে নিচের ৪টি সহজ ধাপে সম্পন্ন করতে পারবেন:

### ধাপ ১: PostgreSQL ডাটাবেস তৈরি করুন
- [Supabase](https://supabase.com) অথবা [Neon.tech](https://neon.tech)-এ একটি ফ্রি অ্যাকাউন্ট খুলে নতুন প্রোজেক্ট তৈরি করুন।
- সেখানে আপনার ডাটাবেসের `Host`, `Database`, `User`, `Port (5432)`, এবং `Password` পাবেন।

### ধাপ ২: PostgreSQL স্কিমা রান করুন
- আপনার প্রজেক্টের `api/database/schema_postgres.sql` ফাইলটি ওপেন করুন।
- Supabase-এর **SQL Editor** অথবা Neon-এর **SQL Console**-এ এই ফাইলের সম্পূর্ণ কোডটি পেস্ট করে **Run** করুন।
- ১ ক্লিকে আপনার সমস্ত ১৪টি টেবিল এবং ইনডেক্স তৈরি হয়ে যাবে।

### ধাপ ৩: `api/.env` ফাইলে কানেকশন পরিবর্তন করুন
আপনার `api/.env` ফাইলে এভাবে কনফিগার করুন:
```env
DB_CONNECTION=pgsql
DB_HOST=ep-your-db-pooler.neon.tech
DB_PORT=5432
DB_NAME=neondb
DB_USER=neondb_owner
DB_PASS=আপনার_পোস্টগ্রেস_পাসওয়ার্ড
```

### ধাপ ৪: cPanel-এ PHP PostgreSQL Extension চালু করুন
- cPanel-এ **Select PHP Version** > **Extensions**-এ যান।
- `pdo_pgsql` এবং `pgsql` বক্সে টিক দিন।
- ব্যাস! আমাদের `api/db.php` ফাইলটি স্বয়ংক্রিয়ভাবে PostgreSQL এর সাথে সংযুক্ত হয়ে যাবে।
